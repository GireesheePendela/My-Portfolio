# 💼 Gireeshee Pendela - Portfolio

A modern, responsive personal portfolio website showcasing my expertise in Data Science, Machine Learning, and Full-Stack Development. Built with React, Vite, and Tailwind CSS for optimal performance and user experience.

## ✨ Features

- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Framer Motion for elegant page transitions and interactions
- **Modern UI/UX**: Clean, professional design with gradient accents and smooth hover effects
- **Project Showcase**: Interactive display of personal and professional projects with links
- **Certifications**: Professional certifications and training with credential verification
- **Skills Display**: Comprehensive skills section with progress indicators
- **Contact Form**: Integrated contact form with email functionality
- **Social Links**: Easy access to GitHub, LinkedIn, and email

## 🚀 Quick Start

### Prerequisites
- Node.js 16.x or higher
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd My-Portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```
   The site will be available at `http://localhost:5173`
